# PluginSound

Плеер с топ-чартами: один веб-интерфейс (`www/`), упакованный в Windows `.exe` (Electron) и Android `.apk` (Capacitor).

## Сборка

Самый короткий путь: GitHub → Actions → **build-pluginsound** → *Run workflow*.
Артефакты: `PluginSound-exe` (portable `.exe`) и `PluginSound-apk` (`PluginSound.apk`, debug-подпись).

Локально:

```
npm install
npm run check          # проверки без сети
npm start              # запуск в Electron
npm run build:win      # dist/PluginSound-1.0.0-x64.exe   (на Windows)
npx cap add android && npx cap sync android
cd android && ./gradlew assembleDebug    # android/app/build/outputs/apk/debug/app-debug.apk
```

Нужны: Node 22, для APK ещё JDK 21 и Android SDK. После первого `npm install` закоммитьте `package-lock.json`.

## Источники чартов

| Вкладка | Что нужно | Статус |
|---|---|---|
| Deezer | ничего | бесплатно, без ключей: мировой топ-50 и 30-сек превью |
| Deezer · страна | ничего | официальный плейлист «Top <страна>» ищется по названию при запуске и кэшируется на неделю |
| VK Музыка | токен доступа VK | экспериментально: у VK нет открытого чарта, нужен токен аккаунта с доступом к аудио |
| Яндекс Музыка | OAuth-токен | экспериментально, формат ответа не проверен на живом сервисе |
| Spotify | Client ID + Secret | экспериментально; у новых приложений доступ к редакторским плейлистам может быть закрыт |
| SoundCloud | client_id | экспериментально, неофициальный `api-v2` |

Чарты обновляются раз в календарный день (и не реже чем раз в 6 часов, пока приложение открыто). При запуске
сразу показывается последний сохранённый чарт, свежий подтягивается в фоне; остальные вкладки прогреваются заранее.
Если обновить не удалось, остаётся сохранённый чарт, а не пустой экран. Ссылки на превью не сохраняются (они протухают)
и запрашиваются заново при воспроизведении.

Иконки сервисов рядом с названием загружаются при запуске с сайтов самих сервисов (через сервис фавиконок Google);
в проекте они не хранятся и не перерисовываются. Без сети вместо них показывается цветная точка.

Звук везде — 30-секундные превью Deezer; полные треки эти сервисы через такие API не отдают.

Все адреса и поля ответов лежат в одном месте: `www/js/sources.js`.

## Графика

Всё нарисовано SVG: `www/img/` (иконка, знак, иллюстрации пустых экранов, волна в hero) и `www/js/art.js` (уникальные обложки для треков без картинки).
PNG/ICO/Android-иконки собираются из SVG командой `npm run icons` (нужны Python, playwright, pillow).
